\subsection{Fetch API dari Jikan API (Manga List)}

    \item Praktikan melakukan parsing data JSON yang diperoleh dari endpoint tersebut untuk menampilkan informasi seperti judul manga, skor, dan jumlah anggota yang menyukai manga tersebut pada halaman web. Kode untuk melakukan parsing data JSON tersebut dapat menggunakan fungsi json\_decode() seperti berikut:
        \begin{lstlisting}[style=phphtml]
<div class="bg-white shadow-md rounded px-8 pt-6 pb-8 mb-4">
    <?php
    $url = "https://api.jikan.moe/v4/top/manga?limit=10";

    $json = @file_get_contents($url);
    $data = json_decode($json, true);

    if($data && isset($data['data'])){

        echo "<div class='grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6'>";

        foreach($data['data'] as $manga){

            $title = $manga['title'];
            $score = $manga['score'];
            $chapters = $manga['chapters'];
            $image = $manga['images']['jpg']['large_image_url'];
            $synopsis = substr($manga['synopsis'],0,120) . "...";

            echo "
            <div class='border rounded-lg shadow hover:shadow-lg transition p-4'>
                
                <img src='$image' class='w-full h-64 object-cover rounded mb-3'>
                
                <h3 class='font-bold text-lg mb-1'>$title</h3>
                
                <p class='text-sm text-gray-600 mb-1'> Score: $score</p>
                <p class='text-sm text-gray-600 mb-2'> Chapters: $chapters</p>
                
                <p class='text-sm text-gray-700'>$synopsis</p>
            
            </div>
            ";
        }

        echo "</div>";

    }else{
        echo "<p class='text-red-500'>Gagal mengambil data manga.</p>";
    }
    ?>
    
</div>
