\section{Tujuan}
\begin{enumerate}
    \item Mahasiswa mampu memahami arsitektur Client-Server dengan memisahkan sisi Backend (API di Ubuntu Server) dan sisi Frontend di Komputer Host.
    \item Mahasiswa mampu melakukan pengujian fungsionalitas REST API (GET, POST, DELETE) menggunakan aplikasi Postman. 
    \item Mahasiswa mampu mengintegrasikan aplikasi Frontend berbasis PHP di sisi klien agar dapat berkomunikasi dan bertukar data dengan REST API yang berada di server.
\end{enumerate}

\section{Dasar Teori}
\subsection{REST API}
REST atau \textit{Representational State Transfer} adalah salah satu arsitektur yang digunakan untuk membangun layanan web yang dapat diakses melalui protokol HTTP. REST API menggunakan pola request-response untuk berkomunikasi antara client dan server. REST API menggunakan metode HTTP seperti GET, POST, PUT, DELETE, dan lain-lain untuk melakukan operasi pada sumber daya yang tersedia di server \cite{dicodingRESTService}

\subsection{JSON}
JSON adalah singkatan dari Javascript Object Notation. JSON adalah format file berbasis teks yang umumnya digunakan dalam proses pertukaran data antara server dan client. JSON banyak digunakan karena formatnya sederhana, sehingga mudah dipahami dan digunakan oleh banyak bahasa pemrograman \cite{hostingerJSONPenjelasan}. 

Kelebihan dari JSON yaitu ringan, serta Bahasa yang independen atau tidak bergantung dan dapat bekerja pada bahasa pemrograman JavaScript dan bahasa pemrograman modern lainnya. Seperti Java, C++, Python, PHP, Ruby, AJAX, dan Perl. Akan tetapi, JSON juga memiliki kekurangan yaitu tidak mendukung komentar, sehingga sulit untuk memberikan penjelasan atau catatan pada data yang disimpan dalam format JSON. Selain itu, JSON tidak memiliki schema yang membuat developer memiliki fleksibilitas total untuk mewakili data dengan cara apa pun dan secara tidak sengaja membuat data yang salah dengan sangat mudah \cite{domainesiaKenalanDengan}.

\subsection{Postman}
Postman adalah sebuah tools atau alat yang populer digunakan untuk mengembangkan dan menguji API (Application Programming Interface). Dengan menggunakan Postman, pengembang dapat membuat permintaan HTTP dan mengirimnya ke server untuk menguji fungsionalitas API yang sedang dikembangkan. Postman menyediakan antarmuka pengguna yang intuitif dan mudah digunakan, sehingga memudahkan pengembang dalam melakukan pengujian API \cite{codepolitanUntukPemula}.

Pada praktikum ini, praktikan akan menerapkan arsitektur Client-Server dengan memisahkan sisi Backend (API di Ubuntu Server) dan sisi Frontend di Komputer Host. Untuk membuat REST API di Ubuntu Server, berikut tahapan yang dilakukan:
\begin{enumerate}
    \item Mengunduh folder kode sumber (source code) API yang telah disediakan yaitu folder sait\_api dan sait\_frontend. 
    \item Buka VS Code yang terhubung dengan Ubuntu Server (Remote SSH).
    \item Copy semua folder kode sumber API ke dalam var/www/html/psait.
    \begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth]{../images/source-code.png}
    \caption{Copy folder kode sumber API ke dalam var/www/html/psait}

    \item Pada praktikum sebelumnya, praktikan telah membuat database dengan nama sait\_db dan tabel mahasiswa. Pastikan database dan tabel tersebut sudah dibuat sebelum menjalankan REST API di Ubuntu Server.
    \item Jalankan perintah berikut untuk mengimport value dari file mahasiswa.sql yang berada di dalam folder sait\_api ke dalam database sait\_db.
    \begin{lstlisting}[style=phphtml]

    \item Verifikasi hasil import dengan masuk ke MySQL dan menjalankan perintah-perintah berikut untuk melihat isi tabel mahasiswa.

    \item Edit file config.php yang ada di dalam folder sait\_api untuk menyesuaikan dengan konfigurasi database yang telah dibuat. Pastikan nama database, username, dan password sudah benar agar REST API dapat terhubung dengan database.

\section{Kesimpulan}
Berdasarkan hasil praktikum yang telah dilakukan, dapat disimpulkan bahwa REST API adalah arsitektur yang digunakan untuk membangun layanan web yang dapat diakses melalui protokol HTTP. REST API menggunakan pola request-response untuk berkomunikasi antara client dan server. REST API menggunakan metode HTTP seperti GET, POST, PUT, DELETE, dan lain-lain untuk melakukan operasi pada sumber daya yang tersedia di server. JSON adalah format file berbasis teks yang umumnya digunakan dalam proses pertukaran data antara server dan client. JSON banyak digunakan karena formatnya sederhana, sehingga mudah dipahami dan digunakan oleh banyak bahasa pemrograman. 

Selain itu, praktikan juga berhasil melakukan pengujian fungsionalitas REST API (GET, POST, DELETE) menggunakan aplikasi Postman. Method GET berhasil dijalankan dengan status code 200 OK dan data yang dikirimkan oleh server dalam format JSON. Method POST berhasil dijalankan dengan status code 200 OK dan dengan pesan "Mahasiswa Added Successfully" untuk menambahkan data baru, serta dengan pesan "Mahasiswa Updated Successfully" untuk memperbarui data. Method DELETE berhasil dijalankan dengan status code 200 OK dan dengan pesan "Mahasiswa Deleted Successfully".

Praktikan juga berhasil menjalankan frontend di komputer lokal yang terhubung dengan REST API di Ubuntu Server. Hal ini menunjukkan bahwa frontend dapat berkomunikasi dan bertukar data dengan REST API yang berada di server, sehingga memungkinkan pengguna untuk mengakses dan memanipulasi data melalui antarmuka pengguna yang disediakan oleh frontend.
