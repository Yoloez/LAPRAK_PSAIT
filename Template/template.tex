\section{Dasar Teori}
\subsection{VPS}
VPS (Virtual Private Server) adalah sebuah layanan hosting yang menyediakan sumber daya server virtual yang terisolasi secara independen di dalam sebuah server fisik. Dengan menggunakan VPS, pengguna dapat memiliki kontrol penuh atas lingkungan server mereka, termasuk instalasi perangkat lunak, konfigurasi, dan manajemen sumber daya. Jika dianalogikan, server fisik adalah rumah, sedangkan VPS adalah kamar-kamar dalam rumah tersebut. Setiap kamar (VPS) memiliki pintu sendiri, sehingga pengguna dapat mengakses dan mengelola kamar mereka tanpa mempengaruhi kamar lain di dalam rumah yang sama \cite{codepolitanVPSPengertian}.

\subsection{SSH}
SSH (Secure Shell) adalah protokol jaringan yang digunakan untuk melakukan remote server atau hosting dengan aman. Hal ini memungkinkan pengguna untuk mengakses dan mengelola server dari jarak jauh melalui koneksi terenkripsi, sehingga data yang dikirimkan antara klien dan server tetap aman dari potensi ancaman keamanan \cite{rumahwebSSHPengertian}.

Cara menggunakan SSH di layanan VPS hampir mirip dengan menggunakan SSH di server lokal. Pengguna dapat menggunakan terminal atau command prompt untuk menjalankan perintah SSH, seperti "ssh username@hostname" untuk terhubung ke server VPS. Setelah terhubung, pengguna dapat menjalankan perintah-perintah untuk mengelola server, seperti menginstal perangkat lunak, mengelola file, dan melakukan konfigurasi.

\subsection{LAMP Stack}
LAMP Stack adalah singkatan dari Linux, Apache, MySQL, dan PHP. Dengan menggunakan keempat komponen tersebut, pengguna dapat membangun dan menjalankan aplikasi web yang kuat, fleksibel, dan hemat biaya. Keunggulannya terletak pada kemampuannya untuk menawarkan solusi berbasis open-source untuk pengembangan web \cite{idwebhostLAMPStack}.

\subsection{Instalasi Web Server Apache di Ubuntu Server}
Sebelum menginstal Apache, pastikan sistem operasi Ubuntu Server sudah terupdate dengan menjalankan perintah berikut di terminal:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
sudo apt-get update
\end{lstlisting}

Setelah itu, untuk menginstal Apache, jalankan perintah berikut:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
sudo apt install apache2 -y
\end{lstlisting}

Setelah proses instalasi selesai, Apache akan otomatis berjalan. Untuk memeriksa status Apache, jalankan perintah berikut:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
sudo systemctl status apache2
\end{lstlisting}

\end{figure}

Dapat dilihat pada gambar \ref{status-apache}, bahwa Apache telah berjalan dengan status "active (running)". Untuk menguji apakah Apache sudah terinstal dengan benar, praktikan dapat membuka browser dan memasukkan alamat IP server Ubuntu. Jika muncul halaman default Apache, berarti instalasi berhasil.

\subsection{Instalasi Php di Ubuntu Server}
Untuk menginstall PHP beserta modul-modul yang diperlukan, jalankan perintah berikut di terminal:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
sudo apt install php libapache2-mod-php php-mysql -y
\end{lstlisting}
Setelah proses instalasi selesai, untuk memeriksa versi PHP yang terinstal, jalankan perintah berikut:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
php -v
\end{lstlisting}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{../images/php-v.png}
    \caption{Versi PHP yang terinstal di Ubuntu Server}
    \label{php-v}

Dapat dilihat pada gambar \ref{php-v}, bahwa PHP versi 8.3.6 telah berhasil diinstal di Ubuntu Server. 

\subsection{Instalasi Databse MySQL di Ubuntu Server}
Untuk menginstall sistem manajemen basis data MySQL, jalankan perintah berikut di terminal:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
sudo apt install mysql-server 
\end{lstlisting}

Setelah proses instalasi selesai, jalankan perintah berikut untuk masuk ke MySQL Shell:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
sudo mysql
\end{lstlisting}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{../images/sudo-mysql.png}
    \caption{MySQL Shell setelah instalasi}
    \label{mysql-shell}
\end{figure}
Jika berhasil, muncul tampilan Welcome dari MySQL Shell seperti pada gambar \ref{mysql-shell}. 
Sebelum melakukan uji coba koneksi, pastikan tujuan dari koneksinya sudah terbuat terlebih dahulu. Buat database baru di MySQL dengan nama sait\_db, dengan menjalankan perintah berikut:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
create database sait_db;
\end{lstlisting}

Setelah database berhasil dibuat, buat user baru dengan nama "mahasiswa" dan password "password123", serta berikan hak akses penuh ke database sait\_db dengan menjalankan perintah berikut:
\begin{lstlisting}[language=terminal, style=ubuntuserver]
    create user 'mahasiswa'@'localhost' identified by 'password123';
\end{lstlisting}
\begin{lstlisting}[language=terminal, style=ubuntuserver]
    grant all privileges on sait_db.* to 'mahasiswa'@'localhost';
\end{lstlisting}

\begin{lstlisting}[language=terminal, style=ubuntuserver]
    flush privileges;
\end{lstlisting}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{../images/create-db.png}
    \caption{Membuat database dan user baru di MySQL}
    \label{create-db}
\end{figure}

Setelah database dan user berhasil dibuat, praktikan dapat membuat file PHP untuk menguji koneksi ke database MySQL. Untuk membuat file php, buka folder web server di VScode yang terhubung ke server Ubuntu, yang berada di folder /var/www/html. User tidak memiliki akses untuk membuat file baru di folder tersebut, sehingga perlu menjalankan perintah berikut di terminal untuk memberikan hak akses ke folder tersebut:

\begin{lstlisting}[language=terminal, style=ubuntuserver]
    sudo usermod -aG www-data $USER
    sudo chown -R www-data:www-data /var/www/html
    sudo chmod -R 775 /var/www/html
\end{lstlisting}

Untuk memastikan bahwa izin telah dijalankan sistem, jalankan perintah "id". 
\begin{figure}[H]

Oleh karena itu, perlu menjalankan perintah "sudo reboot" untuk merestart server agar perubahan izin dapat diterapkan. Setelah server berhasil direstart, jalankan kembali perintah "id" untuk memastikan bahwa praktikan sudah memiliki akses ke folder web server.
